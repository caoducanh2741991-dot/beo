FFmpeg 8.1.3, unmodified official source archive included.
Source: https://ffmpeg.org/releases/ffmpeg-8.1.3.tar.xz
License: LGPL 2.1 or later (see LICENSE-FFmpeg.txt).
Standalone command-line executable; V15 communicates through files and a subprocess.
Windows x86_64 build, MinGW-w64 GCC 13 POSIX. No optional external codecs, no network support.
Extract the included archive, enter ffmpeg-8.1.3 and run:
./configure --extra-ldflags=-static --target-os=mingw32 --arch=x86_64 --enable-cross-compile --cc=x86_64-w64-mingw32-gcc-posix --cross-prefix=x86_64-w64-mingw32- --disable-autodetect --disable-everything --disable-network --disable-debug --disable-doc --disable-x86asm --disable-shared --enable-static --enable-small --enable-ffmpeg --disable-ffplay --disable-ffprobe --enable-protocol=file,pipe --enable-demuxer=mov,mp3,wav,aac,flac,ogg,matroska --enable-decoder=aac,aac_fixed,mp3float,mp3,pcm_s16le,pcm_s24le,pcm_s32le,pcm_f32le,pcm_f64le,pcm_s16be,pcm_s24be,pcm_s32be,pcm_u8,flac,vorbis,opus,alac --enable-encoder=pcm_s16le,pcm_f32le,pcm_s24le,pcm_s32le --enable-muxer=wav,null --enable-parser=aac,mpegaudio,flac,opus,vorbis --enable-filter=volume,atempo,loudnorm,aresample,apad,atrim,asetpts,aformat,anull
make -j8

Only Windows system DLLs are required. No GPU/CUDA dependency.
The native Linux verification build uses the same component switches, with cross-compilation options removed. Windows PE execution could not be performed in this environment.
