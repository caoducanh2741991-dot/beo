# V15 Voice Studio 1.4.6 verification

Scope: fix the missing `pcm_f32le` encoder and MP4 audio import capability; preserve preview WAV before playback; add long-form TXT reading, live duration estimates, persistent sentence audio, regeneration/history/locking, queue duration and safe continuation. Preserve installed GPU/model packages.

Environment: Mono/Linux and Microsoft .NET Framework 4.5 reference assemblies. The shipped standalone Windows x64 FFmpeg executable was cross-compiled from the included unmodified official FFmpeg 8.1.3 source archive. Its enabled components and PE import table were verified. Runtime media tests used a native Linux build from that exact source and identical component switches. The Windows PE could not be executed here because Wine could not create its required local socket. No physical Windows/RTX 2070 test or fresh 2,000-word neural inference was performed.

New feature coverage: Update146Tests has 32 assertions, including a 2,000-word/100-sentence fixture, preservation of words and order, paragraph boundaries, abbreviation/decimal handling, bounded splitting of extremely long sentences, fixed selected reading speed, exact master sample count, provisional/final duration updates, reopening/cache reuse, changing one sentence, master loudness without resynthesis, prior audio version restore, paragraph locking/config changes, error and cancellation recovery, resuming the same partially measured project, breath room, four input formats, queue persistence and migration from earlier TXT queue metadata. The synthesis fixture is deterministic test audio; these are workflow checks, not model-quality or throughput benchmarks.

Actual audio processing: Media146Tests has 12 assertions against the native build matching the Windows component configuration, exercising real VANZAI MP4, MP3/M4A converted from the provided reference, actual ADAM WAV, selected 6-second excerpts, safe true peak, exact final frame count, -18 LUFS normalization and the atempo path. Update145Tests retains its 53 passing assertions with actual ADAM/EXCITER WAV normalization and VANZAI selection. No actual user audio is bundled in this release.

UI: legacy UI suite and 46 Ui146Tests assertions pass, covering six tabs, handle recreation, version 1.4.6.0, device settings, shared punctuation/loudness, natural TXT activation, provisional timing, a fixed timing panel that remains visible while settings scroll, natural controls, persistent archive, locking/unlocking, busy-state controls and restoring the latest TXT project. Studio is rendered through Xvfb for layout review. Audio playback on the user's actual Windows audio device remains outside this environment.

Other regressions: 13 core, 12 batch, 20 features, 17 update141, 8 breath streaming, 20 punctuation, 14 native-device fixtures, 21 updater, 6 ONNX updater, 11 Python device-policy and 4 worker-probe checks pass. Clone generation/protocol/lifecycle suites retain 18 + 9 + 23 passing checks using failure injection and synthetic workers. Production worker changes are limited to safer text splitting; GPU policy, native GPU source and external-process lifecycle are byte-identical to 1.4.5.

Release verification: Release146Tests.py verifies exact archive CRC/unique paths, every payload hash, Windows FFmpeg and matching source archive inclusion, core manifest, complete folder and ZIP updates from prior installed versions, compatibility with existing 1.4.3.1/1.4.4/1.4.5 updaters, preservation of model/CUDA/old audio tool/voice/catalog/settings/script fixtures, rollback cleanup, downgrade rejection, version 1.4.6.0 and net45 String.Contains(Char) compatibility scan. Execute after package_release.py.

Limitations: no runtime ASR proof of every spoken word; no clone-likeness percentage claim; estimated duration ranges have no fixed statistical confidence guarantee; internal sentence timeline does not imply word-level alignment; bounded archive may evict old audio and retains only one prior waveform per fragment; unsupported, truncated or corrupted MP4 inputs can still fail. The exact MP4 shown in the user's first error screenshot was not provided and therefore was not reproduced. FFmpeg LGPL notice, matching source tarball, license and build instructions are included in source/media.
